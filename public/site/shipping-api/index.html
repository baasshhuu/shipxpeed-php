Shipping API

Build shipping into your own systems.

Use the Shipxpeed API to check rates, create shipments, fetch labels and receive tracking updates from your ERP, OMS or custom store.

Planned endpoints

What the API covers.

Illustrative overview. Final paths and fields are in the documentation shared with API accounts.

MethodPathPurpose
POST/v1/ratesRates and serviceability for a route and parcel
POST/v1/ordersCreate an order and book a shipment
GET/v1/shipments/{awb}/labelDownload the shipping label
GET/v1/shipments/{awb}/trackTracking timeline for an AWB
POST/v1/ndr/{awb}/actionReattempt, update address or return
POST/v1/webhooksSubscribe to status events
